తా॥ స్త్రీపురుషులకు తారాబల గ్రహబలముల ముఖ్యతను చెప్పుచున్నాడు. పురుషులకు సూర్యబలము, స్త్రీలకు గురుబలము, స్త్రీపురుషులకు తారాబల చంద్రబలములును ముఖ్యము లై నవని చెప్పంబడెను.

## PDF p.043

గో చార ద ర్శి ని.  31

సూర్యునియొక్క ప్రత్యేక ఫలములు.

శ్లో॥ దేహార్తిశ్చిత్తసంతాపః కాలాతిక్రమభోజనం ।
బంధుమిత్రసుహృద్ద్వేషః చంద్రరాశిగతే రవౌ॥

టీక॥ రవౌ = సూర్యుఁడు, చంద్రరాశిగతే = అనగా చంద్రలగ్నమును బొందినవాఁడయ్యెనేని, దేహార్తిః = దేహమునకు పీడయు, చిత్తసంతాపః = హృదయమున సంకటము, కాలాతిక్రమభోజనం = వేళయతిక్రమించి భోజనము సేయుట, బంధుమిత్రసుహృద్ద్వేషః = చుట్టములతోడ, స్నేహితులతోడ, సాధువులతోడ, విరోధము స్యాత్ = కలుగును.

తా॥ సూర్యుడు చంద్రరాశిని బొందినవాఁడయ్యెనేని శరీరమునందు బాధయు, మనస్సున సంకటమును, వేళనతిక్రమించి భోజనము సేయుట, చుట్టములతోడ, స్నేహితులతోడ, సాధువులతోడ, విరోధము ఇవి కలుగునని తా॥

శ్లో॥ హీనత్వం దుష్టసంసర్గో మనస్తాపశ్శిరోవ్యథా ।
నిష్ఫలం కృషివాణిజ్యం ద్వితీయరాశిగతే రవౌ॥

టీ॥ రవౌ = సూర్యుఁడు, ద్వితీయరాశిగతే = చంద్రలగ్నమునకు రెండవయింటైన ధనస్థానమును బొందినవాఁడైనేని, హీనత్వం = నీచత్వమును, దుష్టసంసర్గః = దుర్మార్గులతో సహవాసము, మనస్తాపః = హృదయమునందు సంకటము, శిరోవ్యథా = తలనొప్పియు, కృషివాణిజ్యం నిష్ఫలం = సేద్యము వర్తకవ్యాపారము ఇవి వ్యర్థములైపోవుట కలుగును.

తా॥ సూర్యుఁడు ధనరాశిని బొందినవాఁడయ్యెనేని నీచత్వము దుర్మార్గులతో గూడిక, మనస్సంకటము, తలనొప్పి, సేద్యము, వర్తకవ్యాపారము ఈకంటియందు లాభములేకపోవుట, ఇవి కలుగునని తాత్పర్యము.

శ్లో॥ ఆరోగ్యం నిత్యసంతోషః బంధుమిత్రసమాగమః ।
అర్థలాభః పుత్రసౌఖ్యమిష్టసిద్ధిస్తృతీయగే॥

టీక॥ సూర్యుఁడు తృతీయే = చంద్రరాశికి మూఁడవరాశిని బొందినవాఁడయ్యెనేని, ఆరోగ్యం = ఆరోగ్యమును, నిత్యసంతోషః = యెడతెగని సంతోషము, బంధుమిత్రసమాగమః = బంధువులతోడను, స్నేహితులతోడను కలసియుండుట, అర్థలాభః = ద్రవ్యలాభము, పుత్రసౌఖ్యం = కుమారులవలన సౌఖ్యమును, ఇష్టసిద్ధిః = ఇష్టములు సిద్ధించుట (ఇవి కలుగును)

తా॥ సూర్యుడు తృతీయరాశిని బొందినవాఁడయ్యెనేని శరీరమునందు రోగములు తొలంగి సుఖముగనుండుటయు, మనస్సున ఉల్లాసము, చుట్టములతోడను స్నేహితులతోడను కలసియుండుట, ధనప్రాప్తి కుమారులవలన సౌఖ్యము ఇష్టములు సిద్ధించుట ఇవి కలుగునని తా॥

శ్లో॥ అంతఃక్లేశం గృహచ్ఛిద్రం సౌఖ్యహానిరభోజనం ।
ప్రయాణవిఘ్నమాప్నోతి చతుర్థే రవిసంయుతే॥

టీక॥ యదా చంద్రరాశికి చతుర్థే రవిసంయుతే = సూర్యునితో జేరినదగుచుండగా అంతఃక్లేశం = హృదయమునందు సంకటమును, గృహచ్ఛిద్రం = ఇంటిలో కలహమును, సౌఖ్యహానిం = సుఖము లేకుండుటను, అభోజనం = భోజనసౌఖ్యము లేకుండుటను, ప్రయాణే = పయనమునందు, విఘ్నం = విఘ్నమును, ఆప్నోతి = పొందగలడు.

తా॥ సూర్యుఁడు చంద్రరాశికి నాలుగవరాశిని ప్రవేశించినవాఁడయ్యెనేని హృదయమున సంకటము, ఇంటిలో ఛిద్రములు, సుఖము లేకుండుట, భోజనసౌఖ్యములేకపోవుట, ప్రయాణము విఘ్నమగుట ఇవి కలుగునని తాత్పర్యము.

శ్లో॥ దేహాలస్యం మనస్తాపం సుహృత్క్లేశం ధనవ్యయం ।
బుద్ధిచాంచల్యమాప్నోతి పంచమే రవిసంయుతే॥

టీ॥ పంచమే = అయిదవరాశి, రవిసంయుతే = సూర్యునితో జేరినదగుచుండగా దేహాలస్యం = శరీరమున సోమరితనమును, మనస్తాపం = హృదయమున పరితాపమును, సుహృత్క్లేశం = స్నేహితులవలన కష్టములును, ధనవ్యయం = ద్రవ్యము వ్యయమగుటను, బుద్ధిచాంచల్యం = బుద్ధి స్థిరము నిలువకుండుటయు, ఆప్నోతి = పొందును.

తా॥ సూర్యుఁడు పంచమరాశిగతుఁడయ్యెనేని శరీరమునందు సోమరితనము హృదయమునందు సంకటము స్నేహితులవలన కష్టము ద్రవ్యవ్యయము బుద్ధిస్థైర్యము లేకుండుటను, ఇవి కలుగునని తాత్పర్యము.

శ్లో॥ సుప్రవాసం సౌఖ్యాదీన్ యత్నకార్యార్థసాధనం |
దేహారోగ్యాదిసంతోషం వస్త్రధాన్యాదిలాభకృత్ ॥

టీ॥ రవౌ = సూర్యుఁడు, షష్ఠే = ఆఱవరాశిని జేరినవాడయ్యెనేని, సుసౌఖ్యాదీన్ = మంచిసుఖము మొదలగువానిని, యత్నకార్యార్థసాధనం = ప్రయత్నించిన పనుల సాధించుటను, దేహారోగ్యాదిసంతోషం = శరీరారోగ్యము మొదలగువాని

వలనం గలుగు సుఖము నిచ్చును మఱియు- వస్త్రధాన్యాదిలాభకృత్ = వస్త్రములు ధాన్యములు మొదలగువానివలన గలుగు లాభమును చేయువాఁడగును.

తా॥ సూర్యుఁడు ఆఱవరాశిని ప్రవేశించినవాడయ్యెనేని మంచిసుఖము, ప్రయత్నించిన కార్యములు సాధించుట, శరీరము సుఖమగనుండుట మొదలుగా వానివలన సంతోషము, వస్త్రలాభము, ధాన్యాదిలాభము కలుగునని తాత్పర్యము.

శ్లో॥ సామంతజనవిద్వేషః దారాపీడా సుతామయం ।
ఉత్సాహభంగకార్యాణి గోచారే సప్తమే రవౌ॥

టీ॥ గోచారే = చంద్రరాశికి, రవౌ = సూర్యుడు సప్తమే = ఏడవయింటిని ప్రవేశించెనేని, సామంతజనవిద్వేషః = సామంతులతో జేరియున్నవారితో మిక్కిలి ద్వేషమును, దారాపీడా = భార్యకు సంకటము, సుతామయం = చిడ్డలకు వ్యాధియును, ఉత్సాహభంగకార్యాణి = ఉత్సాహమునకు భంగకరములయిన కార్యములును సంభవించును.

తా॥ గోచారరీతిగ సూర్యుఁడు ఏడవరాశిని బొందెనేని తనయింటికి గాని దేశమునకుం గాని గలిగిన యెల్లతో జేరియున్నవారితో మిక్కిలి ద్వేషమును, భార్యకు పీడయు, చిడ్డలకు వ్యాధియు, ఉత్సాహమునకు భంగము గలుగజేయు కార్యములును, ఇవి సంభవించునని తాత్పర్యము.

శ్లో॥ దుర్దోషశ్శత్రుసంవాదో గమనాగమనవ్యథా |
దుఃఖవార్తాశ్రుతంచైవ అష్టమస్థో యదా రవిః॥

టీ॥ రవిః = సూర్యుఁడు, యదా = యెప్పుడు, అష్టమస్థః = ఎనిమిదవయింటియందుండునో ఆప్పుడు, దుర్దోషః = ఇడుగుపనులవలనం గలిగిన దోషము, శత్రుసంవాదః = శత్రువులతో కలహము, గమనాగమనవ్యథా = పోకరాకలచేతం గలిగిన బాధయు, దుఃఖవార్తాశ్రుతంచైవ = దుఃఖకరమైన మాటలను వినుటయు (ఇవి కలుగును.)

తా॥ సూర్యుఁడు ఎనిమిదవయింట నుండంగా ఇడుగుపనులవలనం గలిగిన దోషము, శత్రువులతో కలహము రాకపోకలచేతం గలిగిన బాధయు, దుఃఖకరమైన మాటలను వినుటయు, ఇవి కలుగునని తాత్పర్యము.

తా॥ కుజుఁడు మూఁడవరాశిని బొందెనేని ధనలాభము, ఎల్లప్పుడారోగ్యము ఇష్టప్రాప్తి, ధనము, సుఖము, వస్త్రలాభము, ఇవి కలుగునని తాత్పర్యము.

శ్లో॥ భాగ్యహానిర్భయం క్రూరం బంధువైరం ధనక్షయః ।
రోగపీడాదిసంతాపః చతుర్థస్థానగే కుజే॥

టీ॥ కుజే = అంగారకుఁడు, చతుర్థస్థానగే = నాలుగవరాశిని బొందియుండంగా, భాగ్యహానిః = భాగ్యము నశించుట, క్రూరం = క్రూరమగు భయం = భీతియు, బంధువైరం = చుట్టములతో విరోధము, ధనక్షయః = ధనక్షయము, రోగపీడాదిసంతాపః = వ్యాధులవలనం గలిగిన తాపము అలసట మొదలగునవి కలుగును.

తా॥ అంగారకుఁడు నాలుగవరాశిని బొందెనేని భాగ్యము నశించును, క్రూరమగు భయము కలుగును చుట్టములతో విరోధము సంభవించును, ద్రవ్యము నశించును రోగమువలన వేదనలు గలిగి అలసట సంభవించునని తాత్పర్యము.

శ్లో॥ దేహజాడ్యంచ సంతాపః కాలాతిక్రమభోజనమ్ |
దురితం కర్మలాభశ్చ భౌమే పంచమసంస్థితే॥

టీ॥ భౌమే = కుజుఁడు, పంచమసంస్థితే = ౫ వ రాశి యందుండెనేని, దేహజాడ్యంచ = దేహమునందు రోగమును, సంతాపః = తాపమును, కాలాతిక్రమభోజనం = వేళయతిక్రమించి భుజించుటయు, దురితం = పాపము, కర్మలాభశ్చ = పనులు సంభవించుటయు ఇవి కలుగును.

తా॥ కుజుడు ౫ వ రాశి యందుండెనేని, శరీరమునందు రోగము తాపము వేళనతిక్రమించి భుజించుట, పాపమును కర్మములు చేయుటయు ఇవి సంభవించునని తాత్పర్యము.
